# Warehouse Dispatch

| ID | Requirement |
|---|---|
| WMS-01 | Dispatch Management records an order and reserves stock. |
| WMS-02 | If stock is unavailable, hold the order and notify operations. |
| WMS-03 | Operations approves release before Dispatch Management sends an order to the carrier. |
| WMS-04 | The carrier service is required; its vendor is not selected. |

The pilot covers 20 concurrent users. A planning estimate mentions 200 users for production; production capacity is not approved.
